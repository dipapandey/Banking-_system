# Banking System – Mini Project

## Project Overview

The Banking System is a Python-based mini project that simulates basic banking operations through a simple menu-driven application.

The project allows users to create an account, log in using an account number and PIN, and perform common banking activities.

## Features

- Create a bank account
- Generate an account number
- Login using Account Number and PIN
- Check account balance
- Deposit money
- Withdraw money
- Transfer money between accounts
- View transaction history
- Change PIN
- Logout

## Python Concepts Used

- Variables and Data Types
- Conditional Statements
- Loops
- Functions
- Lists and Dictionaries
- String Operations
- Modules

## Modules Used

- `random` – used to generate account numbers
- `datetime` – used to record transaction date and time

## How to Run

1. Make sure Python 3 is installed.
2. Open the project folder.
3. Open a terminal in the project folder.
4. Run the following command:
